# Emmanuel Thomas — Developer Portfolio

A responsive, dark-first, single-page portfolio website built with plain HTML, CSS and JavaScript. No build step or package installation is required.

## Included
- `index.html` — complete website
- Responsive layout for desktop, tablet and mobile
- Dark/light theme toggle
- Scroll progress indicator and active section navigation
- Animated hero text, marquee, floating elements and reveal-on-scroll sections
- Interactive skill filters
- Project detail modals
- Email/contact copy actions
- Command palette (press **Ctrl+K** or **Cmd+K**)
- Keyboard escape handling and reduced-motion support

## Run locally
Open `index.html` in a modern browser. An internet connection is only needed for the Google Fonts stylesheet; the page otherwise runs without a backend.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `emmanuel-portfolio`.
2. Upload `index.html` and this README.
3. Open **Settings → Pages**.
4. Under the build/deployment source, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. After deployment, GitHub will show your public website URL.

You can also deploy the folder with Vercel or Netlify as a static site.

## Before sharing with recruiters
- Replace the generic LinkedIn link (`https://www.linkedin.com/`) with your real profile URL.
- Replace the generic GitHub link (`https://github.com/`) with your real profile URL.
- Add public GitHub repository/demo links for projects where available.
- Confirm the project descriptions match the work you are comfortable representing publicly.
- Optionally add a PDF resume link if you want a direct download button.

## Editing
All content and styles are in `index.html`. Search for a section heading or a project name to update the copy. Colors are defined as CSS variables near the top of the `<style>` block.
